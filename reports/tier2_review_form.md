# Tier-2 Human Domain Expert Review Rubric

## Instructions

For each proposal below, score the following dimensions on a 1-5 scale:
  1 = Strongly disagree (the proposal fails this dimension)
  2 = Disagree
  3 = Neutral / uncertain
  4 = Agree
  5 = Strongly agree (the proposal clearly satisfies this dimension)

Also provide an overall verdict: ACCEPT, REVISE, or REJECT.
You may add comments. Be honest — the goal is to measure whether
these proposals constitute real scientific discovery, not to
validate the system that produced them.

## Scoring dimensions

| ID | Dimension | Question |
|---|---|---|
| D1 | Scientific plausibility | The proposed mechanism (the 'bridge concept') is scientifically plausible given current domain knowledge. |
| D2 | Novelty | The proposed connection between source domains is novel — it is not a trivial or already-well-known connection. |
| D3 | Prediction testability | The prediction stated in the proposal is testable by a concrete experiment or observation. |
| D4 | Falsification rigor | The falsification experiment, if carried out, would rigorously test the proposal (not just confirm it). |
| D5 | Alternative explanations | The proposal honestly considers plausible alternative explanations (not just strawman alternatives). |
| D6 | Counterexample soundness | The counterexample would, if observed, genuinely weaken or falsify the proposal. |
| D7 | Overall scientific value | If the proposal is correct, it would advance the field in a meaningful way (not just an incremental observation). |

## Overall verdict options: ACCEPT, REVISE, REJECT
