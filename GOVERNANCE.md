# GOVERNANCE

## Objective, Month 1

Not: build more.
Is: discover what is actually true.

## Working Protocol

| Principle | Meaning |
|---|---|
| Architecture is a hypothesis. | Elegant ideas are not evidence. |
| Integration is an experiment. | Components either work together or they do not. |
| Benchmarks are measurements. | Measurements replace intuition. |
| Verification is confrontation with reality. | The system must be allowed to fail. |
| Observation is learning. | Production behavior is part of the model. |
| Calibration is adaptation. | Parameters change when evidence changes. |
| Trust is earned slowly. | Long-term reliability matters more than isolated successes. |

See CONSTITUTION.md Law 8 for the formal verification rule this protocol
enforces.
